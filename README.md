# ASU Salesforce Enterprise

Enterprise Git repository for Arizona State University's Salesforce instance

### Metadata Contents

The following metadata types are contained in this repository:

-   ApexClass
-   ApexComponent
-   ApexPage
-   ApexTrigger
-   AuraDefinitionBundle
-   ConnectedApp
-   CustomApplication
-   CustomLabels
-   CustomMetadata
-   CustomObject
-   CustomPageWebLink
-   CustomTab
-   EmailServicesFunction
-   ExternalDataSource
-   FlexiPage
-   GlobalValueSet
-   Group
-   Layout
-   LightningComponentBundle
-   LiveChatAgentConfig
-   LiveChatDeployment
-   NamedCredential
-   QuickAction
-   RemoteSiteSetting
-   SamlSsoConfig
-   Settings

### Development Protocols

-   Prettier, a code formatter, is required for development on crm-salesforce-enterprise
-   Environment setup instructions are available [here](https://asudev.jira.com/l/c/VrE21oBJ)

### Updating Feature Branches

Details on how to update all feature branches after commits are pushed to ASU/main are available [here](https://asudev.jira.com/l/c/15zCXpB6)
