# ASU Salesforce Metadata

Enterprise Git repository for Arizona State University's Salesforce instance

### Metadata Contents
The following metadata types are contained in this repository:

* ApexClass
* ApexComponent
* ApexPage
* ApexTrigger
* AuraDefinitionBundle
* ConnectedApp
* CustomApplication
* CustomLabels
* CustomMetadata
* CustomObject
* CustomPageWebLink
* CustomTab
* EmailServicesFunction
* ExternalDataSource
* FlexiPage
* GlobalValueSet
* Group
* Layout
* LightningComponentBundle
* LiveChatAgentConfig
* LiveChatDeployment
* NamedCredential
* QuickAction
* RemoteSiteSetting
* SamlSsoConfig
* Settings

### Code Formatting
Prettier, a code formatter, is required for development on asu-salesforce-metadata. It's maintained [within the repository](vscode/prettier/.prettierrc).

### Updating Feature Branches
See https://asudev.jira.com/l/c/15zCXpB6 for details on how to update all feature branches after commits are pushed to master.
